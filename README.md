# みんなの安全マップ (Hazard Map) 🔰

子どもから大人まで誰でも直感的に分かりやすく、地域の危険箇所（交通、防犯、災害、街灯、その他）を可視化・共有できる親しみやすいマップアプリケーションです。

---

## 🌟 実装機能一覧

- 🗺️ **子供向けイラスト風マップ表示**
  - かわいいドロップピン＋絵文字アイコン（🚗 👮 🌊 🌙 🐾）で直感的に確認可能
  - 投稿者自身の報告には特別バッジ「👑 じぶん」を表示
  - ピン選択時には楽しく跳ねるアニメーション（「ここ！📍🎯」）

- 🔍 **危険カテゴリ別の絞り込みフィルター**
  - 「ぜんぶ 🌈」「くるま 🚗」「ふしんしゃ 👮」「じしん・かじ 🌊」「くらみち 🌙」「そのほか 🐾」のワンタップ切替
  - リアルタイムな件数バッジ付き

- 📏 **危険度（Lv.1〜5）に応じたマーカーサイズ＆警告タグ**
  - 危険度（1～5）に応じてピンの大きさが自動拡大
  - 高危険度（Lv.4〜5）のピンには赤点滅タグ（`⚠️ Lv.5`）と発光効果を表示

- 🔥 **ヒートマップ（危険ゾーンオーラ表示）**
  - 危険度に応じた半透明の円形オーラ（30m～150m）をマップ上に自動描画
  - フィルターバー右側の「🔥 きけんゾーン」ボタンでいつでも表示・非表示を切替可能

- ⏰ **時間帯選択＆ワンタップスタンプタグ**
  - 危険な時間帯（☀️ 朝・昼 / 🌆 夕方 / 🌙 夜 / ⏰ 一日中）を指定
  - 「＃くるまがはやすい」「＃とびだしちゅうい」などのワンタップスタンプで簡単入力

- 🎈 **子ども向けひらがな通知（トースト案内）**
  - 未入力や未選択時に「📍 まず ちずの あぶない ばしょを ぽちっと おしてね！」など親切なひらがなメッセージで案内

- 💬 **地域コメント＆写真投稿**
  - 各報告にコメントを残せる交流機能
  - 現地の写真を撮影・添付して投稿可能

---

## 🛠️ 技術スタック

- **フロントエンド**: React 19, TypeScript, Vite, React Leaflet (OpenStreetMap), HTML5/CSS3
- **バックエンド**: Node.js, Express 5, TypeScript (tsx), Multer (画像アップロード)
- **データストレージ**: JSONファイルデータベース (`backend/data/hazards.json`)

---

## 🚀 運用・起動手順

### 1. バックエンドの起動
```bash
cd backend
npm install
npx tsx server.ts
```
バックエンドAPIサーバーが `http://localhost:3001` で起動します。

### 2. フロントエンドの起動
```bash
cd frontend
npm install
npm run dev
```
ブラウザで [http://localhost:5173](http://localhost:5173) にアクセスしてください。
